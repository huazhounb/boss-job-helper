# BOSS 岗位投递助手

自动筛选岗位、批量打招呼，少做重复点击。

**v2.2.1 · 内测版 · 电脑端用户脚本 · AGPL-3.0-or-later**

设置岗位和城市关键词，先预览匹配结果，再开始逐个沟通。支持排除词、经验/学历标签、批次休息、实时倒计时、紧凑面板和日志导出。AI 是可选功能，默认关闭，普通列表沟通不需要配置 API。

![本地模拟运行面板](docs/images/running-panel.png)

> 上图来自本地模拟页面。“新沟通”“旧会话”是按钮点击数，不代表对方收到消息。脚本面向 BOSS 网页版，手机用于设置账户默认招呼语，不用于运行本脚本。

## 三分钟开始

1. 在电脑浏览器安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 打开油猴的扩展详情，开启**允许用户脚本**；没有此开关时，按[官方权限说明](https://www.tampermonkey.net/faq.php#Q209)检查开发者模式和执行权限。
3. 在油猴中**添加新脚本**，删除编辑器里的默认内容，打开本仓库的 [boss-helper.user.js](boss-helper.user.js)，复制**完整代码**进去，按 `Ctrl+S` 保存并启用。
4. 先在手机 BOSS App 中确认并设置自己的**默认招呼语**，再回电脑打开 [BOSS 网页版](https://www.zhipin.com/)并登录。
5. 进入岗位列表。如果面板已经打开，直接操作；如果只看到右下角纸飞机图标，点击它展开。
6. 输入岗位、城市和排除词。**多个词用英文逗号 `,` 隔开**，先点“预览当前列表匹配”，确认后点“启动投递”。

只启用一份助手。普通使用只需安装 `boss-helper.user.js`，不需要 Node.js，也不需要安装本仓库的开发依赖。

**带图详细教程：**[安装与首次使用](docs/INSTALL.md)

## 关键词怎么填

| 设置项 | 可复制示例 | 含义 |
| --- | --- | --- |
| 岗位关键词 | `前端开发,Web,AI,Agent` | 岗位标题包含任一关键词即可 |
| 城市关键词 | `广州,深圳` | 城市包含任一关键词；留空不限 |
| 排除词 | `销售,培训` | 卡片文本命中任一词就排除；留空不排除 |

这三组条件会一起生效。经验和学历默认“不限”，只根据当前卡片文字筛选，不分析整份岗位详情。预览只针对页面**已加载**的岗位，不会点击、发送或滚动加载。

## 招呼语要在哪里改

| 使用场景 | 设置位置 |
| --- | --- |
| 岗位列表点击“立即沟通”时的网站默认招呼语 | 在自己的 BOSS 账户中设置，可先通过手机 App 配置 |
| 在聊天页手动启动脚本后发送的自定义介绍 | 助手齿轮 → 沟通话术 |
| 可选 AI 回复使用的求职者资料 | 助手齿轮 → AI 自动回复 → 人设 |

公开版不预填作者的学历、技能、项目或邮箱。聊天话术使用 `[目标岗位]` 等模板占位符，**先改成自己的真实资料**；占位符未替换时不会启动聊天发送。仅在列表批量沟通时，不需要修改这段聊天模板。

## 能做什么

- 按岗位、城市、排除词及经验/学历标签筛选，并预览排除理由。
- 在岗位列表依次处理“立即沟通”和“继续沟通”，支持等待“留在此页”弹窗。
- 显示当前步骤、剩余等待时间，以及扫描、新沟通、旧会话、跳过、失败统计。
- 按每轮上限和批次参数休息，可随时停止；运行时锁定筛选，停止后可编辑。
- 手动在聊天页启动后，按顺序处理话术与简历入口，保留手动草稿和分步记录。
- 最小化为纸飞机图标、切换紧凑面板、复制或导出最近 120 条日志。

跨页面路径切换会停止并提示手动启动，刷新后也不会自动恢复。实际匹配和按钮适配依赖网站页面结构。本项目不保证最终送达、回复、面试结果或绕过网站限制。
