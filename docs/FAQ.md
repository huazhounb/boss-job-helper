# 常见问题

## 安装后没有面板或纸飞机图标

确认在 `zhipin.com` 的网页上，油猴扩展和这份脚本都已启用，扩展有该站点访问权限，并已按 [安装教程](INSTALL.md)打开“允许用户脚本”或当前版本要求的权限。保存脚本后刷新网页。只启用一份助手，避免两个版本冲突。

## 找不到“允许用户脚本”

浏览器和扩展版本可能不同。按 [Tampermonkey 官方 FAQ Q209](https://www.tampermonkey.net/faq.php#Q209)检查开发者模式、允许用户脚本以及首次执行授权。无需为了本脚本打开 InPrivate 或本地文件访问权限。

## 我已经改了手机招呼语，为什么助手设置里还是模板

这是两个位置：列表“立即沟通”使用 BOSS 自身的招呼机制；助手里的模板用于在聊天页手动启动后发送的介绍。手机与电脑用同一账户。手机功能是否提供、修改是否生效，以账户实际页面和人工沟通结果为准。

## 默认模板提示我填写资料，怎么办

点击齿轮，在“沟通话术”中将 `[目标岗位]`、`[相关技能/经验]`、`[到岗时间]` 替换为真实内容，保存后再启动聊天。只使用列表批量沟通，不需要改这段模板。

## 为什么有些岗位被排除了

点击预览查看原因。检查英文逗号格式、城市、排除词以及经验和学历筛选。所有维度同时生效；筛选根据卡片文字，不读取详情页，也不推断缺失信息。

## 一直显示批次休息，是卡住了吗

通常是在执行已设置的休息，顶部显示剩余秒数。到时会继续，也可点击“立即停止”。日志可用于核对当前步骤，不需要反复点击启动。

## 点击数增加了，为什么看不到新消息

点击数不等于送达数。“继续沟通”也是一次旧会话点击。网站可能有延迟或其他限制，需查看页面实际结果。脚本不保证每次点击都产生新会话或送达。

## 聊天页为什么没有自动接着运行

本版本保留手动启动方式，跨路径切换后停止，需在新页面单独启动。刷新也不会自动恢复。

## 话术发送待核对怎么办

先打开实际会话确认是否已经发送。脚本没有确认到回显时不会反复重发。简历暂不可用时会保留话术进度。不要在尚未确认结果时反复清记录重试；“清记录”会清空所有 HR 处理进度。

## 是否需要开 AI、填写 API Key

普通列表沟通不需要。AI 是可选项，默认关闭。启用后请使用自己的接口和资料；错误状态会显示在日志中。

## 手机上能运行这个脚本吗

本项目教程和测试针对电脑浏览器。教程中的手机步骤是设置 BOSS 账户默认招呼语，不代表在手机 App 内运行脚本。

## 如何反馈问题

在 GitHub Issues 中说明脚本版本、浏览器、所在页面、复现步骤及实际结果，附上去除姓名、联系方式、Key 等个人信息后的日志或截图。不要提交 Cookie、账户登录数据或完整私聊记录。
